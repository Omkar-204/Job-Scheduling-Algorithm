"Job Scheduling with Deadline"

A greedy approach to maximize profit with deadline constraints

Done By: O64,065,066,086

Theoretical Background

Job scheduling with deadlines is a method used in computing and operations research to allocate tasks efficiently while ensuring they are completed within a specific time. The concept dates back to early computer systems in the 1950s when batch processing required scheduling jobs based on priority. Over time, research in the 1970s and 1980s led to the development of real-time scheduling algorithms like Earliest Deadline First (EDF). The core idea is to manage multiple tasks with different deadlines by optimizing resource usage, reducing delays, and avoiding system overloads. Today, job scheduling is widely used in operating systems, cloud computing, and industrial automation to improve performance and reliability.

Problem Definition:

Given a set of jobs, each with:

  • Job ID: A unique identifier for each job
  • Profit: The profit earned upon completing the job
  • Deadline: The latest time by which the job must be completed

We need to find the sequence of jobs that maximizes the total profit, assuming:

  • Each job takes exactly one unit of time to complete
  • Only one job can be processed at a time
  • A job earns profit only if completed before its deadline

Algorithm Implementation:

The greedy algorithm for this problem follows these steps:

  1. Sort all jobs in decreasing order of profit
  2. Initialize a result sequence with 'empty' slots equal to the maximum deadline
  3. For each job in the sorted order:
    • Find the latest available time slot before the job's deadline
    • If such a slot exists, assign the job to that slot

Implementation Code:


            ```cpp
            #include <iostream>
            #include <vector>
            #include <algorithm>
            
            struct Job {
                int id;
                int profit;
                int deadline;
            };
            
            // Comparator function to sort jobs in decreasing order of profit
            bool compare(Job a, Job b) {
                return a.profit > b.profit;
            }
            
            std::pair<std::vector<int>, <int> scheduleJobs(std::vector<Job>& jobs) {
                // Sort jobs in decreasing order of profit
                std::sort(jobs.begin(), jobs.end(), compare);
                
                // Find the maximum deadline
                int maxDeadline = 0;
                for (const auto& job : jobs) {
                    maxDeadline = std::max(maxDeadline, job.deadline);
                }
                
                // Initialize result array with -1 (empty slots)
                std::vector<int> result(maxDeadline, -1);
                
                // Initialize total profit
                int totalProfit = 0;
                
                // Schedule each job
                for (const auto& job : jobs) {
                    // Find the latest available slot before deadline
                    for (int i = std::min(maxDeadline, job.deadline) - 1; i >= 0; i--) {
                        if (result[i] == -1) {
                            result[i] = job.id;
                            totalProfit += job.profit;
                            break;
                        }
                    }
                }
                
                // Filter out empty slots
                std::vector<int> scheduledJobs;
                for (int id : result) {
                    if (id != -1) {
                        scheduledJobs.push_back(id);
                    }
                }
                
                return {scheduledJobs, totalProfit};
            }
